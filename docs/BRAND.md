## 1. ブランドの位置づけ（才気道との関係）

HSP Partner は、才気道（saikido.org）への入口となる「子」ブランドです。
読者は記事 → 公式LINE → 才気道へと進むため、両者に"血縁"を感じさせます。

| | 才気道（親） | HSP Partner（子） |
|---|---|---|
| 役割 | 深める・極める（哲学・商品） | 出会う・寄り添う（入口・共感） |
| イメージ | 引き算・静寂・道・芯・軸 | 共感・信頼・安心・寄り添う |
| 色 | 濃い藍・紺 | 同じ青系統のパステルブルー |
| フォント | 明朝（静・格式） | ゴシック（親しみ・読みやすさ） |
| 形 | 直線・広い余白 | 角丸・やわらかい影 |

**血縁の作り方**：色は「同じ青のファミリー」で統一し、彩度・明度を上げてパステルに。
役割の違いは、フォント（明朝→ゴシック）と角丸で表現する。

## 2. カラーパレット

| 用途 | トークン | HEX |
|---|---|---|
| 背景の極淡（セクション地） | `brand-50` | `#eff6fd` |
| 淡いタグ・枠 | `brand-100` | `#dbeafb` |
| ホバー・枠線 | `brand-200` | `#c2ddf6` |
| パステルの主役 | `brand-300` | `#9ac8ef` |
| 補助アクセント | `brand-400` | `#6fabe4` |
| ボタン・アクセント | `brand-500` | `#4f93d8` |
| 濃いめのリンク・文字 | `brand-600` | `#3d7ac1` |
| 才気道の藍に近い | `brand-700` | `#335f9c` |
| **見出しの濃紺（血縁）** | `ink` | `#20405f` |

- **見出し（h1〜h2）** は `text-ink`（濃紺）。才気道との血縁＆可読性を担保。
- **タグ・ボタン・リンク** は `brand-500/600`。
- **背景の面** は `brand-50`。
- LINE登録ボタンだけは **LINEグリーン**（`green-500`）を維持。緑＝LINEという認知を利用するため。

## 5. トーン＆マナー（言葉づかいの基準）

### 読者ペルソナ（HSS型HSP・刺激追求寄り）
- 30代。いろいろ挑戦するが**飽きてしまい**、キャリアや成果が積み上がらない。刺激に疲れてダウンする。
- 抱える葛藤：
  - キャリアが定まらず「このままでいいのか」
  - 会社に縛られず自由になりたい
  - 飽きてやめてしまう自分を変えたい
  - 普通に働くだけで毎日ぐったり
  - 完璧主義で歩みが止まる／キャパ超えで頑張りすぎる
  - 行動したいのに怖くて動けない（アクセルとブレーキ同時踏み）
  - 人の感情・場の空気を拾いすぎる
  - 自己肯定感が低く、失敗や指摘を何年も引きずる
  - 感情の浮き沈みが激しく、安定すると刺激を求めだす

### 読後に作りたい状態
**「スッキリ、でも次の問い」**。モヤモヤが軽くなり、かつ解決に向けた次の一歩
（公式LINEなど）が自然に提示されている状態。記事内で全部を解決しきらず、
「もっと知りたい」を残してLINEへ橋を架ける。

### 基本姿勢
**正そうとせず、まず受け止める**。先生ではなく、隣を歩くパートナー。

### 一人称・語尾
- 一人称：「私たち」または運営者の名前
- 語尾：敬体（です・ます）。やわらかく、丁寧に。
- 絵文字：本文では使わない（静けさを保つ）。LINE誘導まわりで最小限ならOK。

### 使う言葉 ◯（ペルソナに合わせた提案・運用しながら更新）
そのままで / あなたのペース / 整える / 寄り添う / 大丈夫 / 理解する / 活かす /
気質 / 強み / 自分らしく / ヒント / 無理なく / 少しずつ / 自由 / 選べる

### 避ける言葉 ✕
- **YMYL／医療を想起させる語**：治す / メンタル / クリニック / 症状 / 診断 / 改善（治療的な意味）
- 克服 / あなたは間違っている / 普通は / 〜すべき / 直す
- 煽り：「知らないと損」「今すぐ」「これだけで人生が変わる」

## 6. コピーを依頼するときのテンプレート

「ダサいコピーを直して」では伝わりません。次の5点をセットで指示します。

1. **誰が読むか**（例：30代、刺激を求め転職を繰り返すが疲弊しているHSS型HSP）
2. **読む前の感情**（例：「自分はおかしいのでは」と不安）
3. **読んだ後に感じてほしい感情**（例：「この気質のままで大丈夫」と安心）
4. **使う言葉／避ける言葉**（上の◯✕に追記）
5. **好き／嫌いな参考例**（既存コピーで「これは好き」「これは嫌い」を2〜3個）

## 7. 記事の構成ルール（SEO＆回遊）

1. 各記事は検索意図に応える見出し（h2）構成にする。
2. 記事末に **LINE誘導の署名欄**（`LineCta`）を置く。
   - ただし記事LP型では、あえて署名欄を外すパターンもある。
3. 署名欄の後に **関連記事**（同カテゴリ優先）＋**人気記事**を表示し回遊を促す。
4. 内部リンクで関連記事へ自然につなぐ。
