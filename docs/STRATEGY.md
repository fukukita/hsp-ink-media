## 1. 才気道とは（親ブランド）

- **B2C**：HSS型HSPの脳内カオスをデトックスする思考整理セッション。
  「やりたいことが多すぎて疲弊している人の思考をデトックスし、本当にやるべきことだけを残す個別セッション」
- **B2B**：アイデア豊富だが頭がカオスになりやすい経営者の思考を整理し、判断ミス（損失）を減らす相談役。
- 主宰：**ふくきた｜才気道 家元**。「HSS型HSPの脳内カオスを鎮火し、生存戦略を設計する」。

### コア哲学：「足す」ではなく「引く」
世のキャリア論は「スキルを足す／資格を取る」。才気道は逆で、**ノイズを引いて、すでに持っているものを活かす**。情報過多で疲弊したHSS型HSPに「もっと頑張れ」とは言わない。
→ サイトのトーン（静か・余白・引き算）と完全に一致させる。

### メソッドの型：整術 → 探術 → 紡術
1. **整術**：脳内カオスを整理し、優先順位を明確化
2. **探術**：強み・価値観を言語化し、判断軸をつくる
3. **紡術**：バラバラの経験を「独自のポジショニング」に統合

## 3. 記事の役割分担（重要）

| 媒体 | 出す情報 | CTA |
|---|---|---|
| **無料記事（このサイト）** | What（何が問題か）／ Why（なぜ起きるか）まで | 末尾で**公式LINEへ誘導**。解決策を出す場合は必ず「次の問い」を立ててLINE・動画へ |
| **公式LINE／メルマガ限定** | How（具体的にどうするか） | 個別セッションのニーズ喚起 |

→ 記事内で全部を解決しきらない。**「スッキリ、でも次の問い」**で終え、Howの手前でLINEへ橋を架ける。

> **2026-09-20 更新（ふくきたさん確定）**：検索で上位を取るため、無料記事にも How を書いてよい。ただし How で終わらせず、「◯◯をやっても△△を見落としていると意味がない」のような次の興味づけを置き、読者から見た「情報の欠け」を作って公式LINEへ導く。その欠けは公式LINEでしか手に入らない展開にする。誘導文は原則 CTA に置き、本文は検索意図を満たすことに集中する（流れで自然に誘導できる記事は無理に変えない）。

## 4. SEO・KW方針

- まずは**HSS型HSP特化**で重要KW上位を狙う。取り終えたらマルチポテンシャライト／スラッシュキャリア等へ横展開。
- ビッグKWを**カニバリさせず網羅的に**設計。CVに繋がらないKWは避ける。
- 悩みが深くCVに繋がるKW：「飽き性」「頭のゴチャゴチャ」「キャリアが積み上がらない」「情報過多で疲れた」など。
- 記事の型：**検索意図を満たす＋オリジナリティ＋EEAT**。文字数 3,000〜6,000字目安。

> **2026-09-20 更新**：文字数は固定しない。対策KWの上位10〜20件（docs/serp/<slug>.md）の本命意図の中央値を目安にし、上位を取るのに必要なら多く、短くても取れるなら短くする。KWの検索量は docs/kw/ の Keyword Tool 書き出しで確かめる。避ける語のうち「診断」は「セルフチェック」に言い換え、「克服」は使わない。医師・カウンセラーは比較対象に入れない。

## 5. 読者の「痛み（Before）」と「変化（After）」＝コピーの金脈

### Before（痛みの言葉。見出し・導入・キャッチに使う）
- 頭のなかがゴチャゴチャで、何から手をつけていいか分からない
- 飽き性でキャリアが積み上がらず、置いていかれる焦り
- 自分の強みが分からない（「強みは？」に答えられない）
- 転職を繰り返して履歴書が傷だらけ。自己肯定感が低い
- 情報収集ばかりで行動できない（ノウハウコレクター）
- 副業や新しい働き方に興味はあるが、何をすればいいか見えない
- 人間関係で消耗しすぎて、仕事に集中できない

### After（変化。記事のゴール提示・LINE訴求に使う）
- 脳内カオスが整理され、優先順位が明確になる
- 強み・価値観が言語化でき、判断軸ができる
- バラバラの経験が独自のポジショニングに統合される
- 「次の一手」が見え、行動に迷わなくなる
- 同じ気質の人と繋がれて、孤独感が減る

### 本質的な悩み
表面：副業を前進させたい／根本：本業のノイズを整理しないと副業も動かない。
→ 「本業・副業・生き方が混然一体となったカオスを、まるごと整理してほしい」状態。
