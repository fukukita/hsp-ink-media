## 運用ルール
- 1記事 = 主KW 1つ。主KWが他記事と被ったら、角度を変えるか統合を検討。
- 記事公開時に「状態」を ✅ に更新し、上の表へ移動。
- 既存エッセイ・音声書き起こしを素材化する際は、上のロードマップで主KWの重複がないか必ず確認する。
- デモ記事（career-akippoi / recovery-habits / accel-brake）はKW管理対象外（本番記事が増え次第削除予定）。
