## 4. なぜ放置されたのか（手順4）

1. **KWを決めるときに検索量の実データを見なかった。** 書き出し（docs/kw/）は 2026-09-20 に初めて共有された。それまでは docs/KW-MAP.md の「主KW」を頭で組み、「HSS型HSP ＋ 悩みの語」なら検索されるはずだと決めていた。実測すると30本中19本のKWが書き出しに無い。
2. **素材（音声・エッセイ）の語彙をそのままKWにした。** 「0→1」「手札」「自己責任」「体力」「予定・余白」「セルフイメージ」「ケアレスミス」「思考整理」は、ふくきたさんの言葉であって検索者の言葉ではない。上位は「仕事続かない」「しんどい」「疲れやすい」「考えすぎ」「ミスが多い」で書いている。kw_before_writing の決まり（素材の語彙をそのままKWにしない）を hsp.ink に遡って当てはめていなかった。
3. **書く前に上位を調べなかった。** 上位10〜20件を表にする決まりは 09-08（ceodock）にできたが、hsp.ink の既存30本には遡って適用していなかった。今日まで serp ファイルは1本も無かった。
4. **記事の型を2,000〜3,500字に固定し、上位に対して足りない分量を測らなかった。** 「リード→チェックリスト→理由→私の話→対処→まとめ」の型で全記事を書いた。上位の中央値は 向いてる仕事 15,500、生きづらい 12,000、会社員 12,500、自己肯定感系 6,500 で、こちらは 1/3〜1/6。
